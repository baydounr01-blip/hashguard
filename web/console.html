This runs in your browser, with WebCrypto, using none of the operator's code. It re-derives each record's hash, walks every inclusion proof to the day's sealed Merkle root, checks that each seal is SHA256d(prev_seal ‖ merkle_root) and that the days chain to each other, and redoes the fee arithmetic in integers. It works because the ledger holds no floating point: your browser and the agent serialise the same bytes.

The agent runs on your own hardware, inside your own network. This page never sees your farm unless you point it at one.

The token is the only thing standing between this page and your farm, and it is the only thing this page stores — in sessionStorage, so it is gone when you close the tab. The agent binds to loopback by default; for remote access put it behind a VPN and use that address here, rather than exposing the port.
